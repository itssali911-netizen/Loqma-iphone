# Calorie card — scoped vector icon sources

These four new template assets are confined to the reference calorie card. Existing application assets were not changed.

Upstream: [Lucide Icons](https://github.com/lucide-icons/lucide), immutable source commit [`2ca268e74888d3506b3319fb8f94aaaaf70ceca9`](https://github.com/lucide-icons/lucide/commit/2ca268e74888d3506b3319fb8f94aaaaf70ceca9).

The source SVG bytes are preserved exactly as downloaded from this commit. No icon package or runtime dependency was added. Each source uses a24×24viewBox, fill=none, stroke-width=2, round line caps and joins. The asset catalog requests template rendering and preserved vector representation; the SwiftUI card supplies its own colors. This does not prove that the reference image originally used Lucide: the family identification is a visual inference from the bitmap.
