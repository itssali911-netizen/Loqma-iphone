# لُقمة 2.9 (120) — نسخة HealthKit لإعادة التوقيع

هذه نسخة iPhoneOS فعلية تتضمن HealthKit الأصلي. تحمل توقيع تجزئة محليًا ADHOC_HASH، وليست موقعة بشهادة Apple ولا تحتوي ملف تزويد. لا تُثبت مباشرة، ولا تمنح صلاحية صحتي تلقائيًا.

1. نزّل IPA وSHA256SUMS من الإصدار نفسه. افحص SHA256 قبل التوقيع.
2. احتفظ بنسخة احتياطية من بيانات لقمة بالطريقة الموجودة بالتطبيق. لا تحذف النسخة الحالية. اختلاف Team أو معرّف التطبيق قد يجعل النظام يعتبرها تطبيقًا آخر؛ لا نضمن انتقال البيانات عند تغييرهما.
3. استخدم أداة توقيع تقبل شهادة وملف تزويد يسمحان بـ`com.apple.developer.healthkit` لمعرّف التطبيق النهائي، أو ابنِ المصدر وثبته عبر Xcode بتوقيع Apple رسمي. حافظ على معرّف التطبيق الحالي وTeam متى أمكن.
4. بعد إعادة التوقيع، افحص **IPA النهائي** على Mac:

```sh
sh Tools/verify-healthkit-signing.sh --ipa FINAL.ipa --output FINAL-report.json
```

أضف `--expected-bundle app.luqma.diary` فقط إذا كان معرّف النسخة النهائي هو نفسه. الفاحص لا يعيد التوقيع، ولا يثبت التطبيق، ولا يمنح أذونات. Exit 2 يعني فحصًا ناقصًا أو حاجة إلى توقيع Apple؛ Exit 1 فشلًا مثبتًا؛ Exit 0 اجتياز الفحوص الساكنة المتاحة فقط.

5. ثبّت النسخة بتوقيع صالح لجهازك وافتح الإعدادات > Apple Health > ربط Apple Health. اختر بنفسك البيانات المراد مشاركتها في نافذة Apple الرسمية. لا تُدخل Apple ID داخل لقمة.
6. استخدم تحديث القراءات واختر الفترة 7/30/90 يومًا. تتم إعادة القراءة عند العودة للتطبيق، مع تحديثات تدريجية أثناء الاستخدام. هذه النسخة لا تطلب مزامنة الخلفية.

تحتاج نافذة Apple توقيعًا متوافقًا. إكمالها لا يثبت السماح بكل أنواع القراءة. «لا توجد قراءة متاحة» قد تعني غياب السجلات أو عدم مشاركتها؛ لن تُعرض كصفر. إدارة الوصول: صحتي > صورة الحساب > التطبيقات والخدمات > لقمة. أسماء القوائم تختلف حسب iOS. إيقاف التحديث داخل لقمة يمسح ذاكرة العرض فقط ولا يسحب أذونات النظام.

لم يُختبر هذا الإصدار على آيفون فعلي أو بحساب مجاني أو عبر iLoader/AltStore/SideStore. لا يوجد ضمان بأن كل حساب أو أداة تدعم HealthKit. راجع تقرير التوافق والتوقيع الفعلي قبل التثبيت.

للبناء من المصدر: يلزم Mac يدعم Xcode حديثًا وSDK iOS 17+ (سكربت البناء يتطلب Xcode 16+، وCI يستخدم26.6). Xcode14.2/macOS12.7.6 لا يبني هذا المشروع. افتح Luqma.xcodeproj واختر Luqma، ثم Team وتوقيعًا تلقائيًا وHealthKit، وصِل جهازك. لا تغيّر Bundle ID لحل خطأ عشوائيًا. بيانات الحساب والشهادة وملف التزويد شخصية ولا تُرفع إلى الإصدار العام.
