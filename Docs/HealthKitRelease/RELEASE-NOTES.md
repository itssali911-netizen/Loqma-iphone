# Luqma2.9 (120) — HealthKit re-signable PREVIEW

Native read-only Apple Health: ten data categories, individual system consent, 7/30/90-day activity history, weight trend, recorded workouts, sleep overlap reconciliation, manual and foreground refresh, incremental foreground change handling, cancellation and truthful partial/empty/error states.

The approved103 application baseline and all meal/calorie assets, layouts, fonts, calculations and navigation are preserved. Health adds its settings section and one conditional Progress card with the requested V5 palette. Manual weights and calorie targets are not overwritten.

This IPA uses local ADHOC_HASH signing, contains no Apple provisioning profile, and requires compatible legitimate re-signing. It is not a public all-device developer-signed build. No physical iPhone, real Health data or third-party installer/account combination is verified. Background delivery is not enabled. Review the included reports and installation guides before signing/installing.
